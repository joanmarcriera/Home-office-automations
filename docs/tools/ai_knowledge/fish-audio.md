# Fish Audio

## What it is
Fish Audio (Fish Speech) is an open-source text-to-speech (TTS) platform designed for high-quality, expressive voice synthesis with minimal latency.

## What problem it solves
It provides a powerful alternative to proprietary TTS services, offering researchers and developers a SOTA open-weights model for audio generation.

## Where it fits in the stack
**Category**: AI Assistants & Knowledge

## Typical use cases
- High-quality voiceovers
- Real-time conversational agents
- Accessibility tools
