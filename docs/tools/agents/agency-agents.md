# Agency-Agents

## What it is
Agency-Agents is a comprehensive suite of specialized AI agents designed to function as a "complete AI agency," with roles ranging from frontend developers to social media specialists.

## What problem it solves
It provides "off-the-shelf" expert agents with predefined personalities, processes, and deliverables, reducing the effort needed to prompt and orchestrate agents for specific business functions.

## Where it fits in the stack
**Category**: Agent / Framework

## Typical use cases
- Rapidly spinning up a specialized marketing or dev team.
- Automating social media community management (e.g., "Reddit community ninjas").
- Enhancing project quality with specialized "reality checkers" or "whimsy injectors."

## Strengths
- High degree of role specialization.
- Proven deliverables and workflows for each agent type.
- Personality-driven interactions that feel more expert-led.

## Limitations
- May require complex orchestration to coordinate many specialized agents effectively.
- Dependency on specific prompting styles or frameworks used by the project.

## When to use it
- When you need more than just a general-purpose assistant and want a "team" of experts.
- For business workflows that map well to traditional agency roles.

## When not to use it
- For simple tasks where a single general assistant (e.g., Claude or ChatGPT) is sufficient.
