# Morgen

## What it is
A cross-platform calendar, task manager, and meeting scheduler that aggregates all your calendars into one place.

## What problem it solves
Eliminates the "multiple calendar" problem by consolidating Outlook, Google, iCloud, and CalDAV into a single, unified interface on desktop and mobile.

## Where it fits in the stack
**Category**: Calendar & Tasks / Unified Scheduling

## Typical use cases
- Unified personal and work scheduling
- Task time-blocking
- Meeting scheduling via links

## Strengths
- Cross-platform support (Windows, macOS, Linux, iOS, Android)
- Supports a wide range of providers (iCloud, Exchange, Google, CalDAV)
- Integrated task management and scheduling links

## Limitations
- Advanced features require a subscription
- No web version (desktop and mobile apps only)

## When to use it
- If you use a mix of Windows/Linux and need a unified calendar
- If you need to manage CalDAV servers alongside Google/Outlook

## When not to use it
- If you only use one calendar provider
- If you prefer a web-based interface

## Licensing and cost
- **Open Source**: No

- **Self-hostable**: No
