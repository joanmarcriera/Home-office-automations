# BreezeTTS2

## What it is
BreezeTTS2 is an open-weights, high-fidelity neural text-to-speech (TTS) framework designed for low-latency, zero-shot voice cloning and controllable natural speech synthesis. Released in early 2026 and widely discussed across open-source audio communities, BreezeTTS2 builds upon sub-word acoustic tokenization and non-autoregressive latent diffusion transformers. In early 2027, BreezeTTS2 serves as a premier local audio synthesis backend for autonomous voice agents, interactive AI assistants, and multi-modal pipeline extensions integrated via the **FastMCP 3.1 Task Protocol**.

## What problem it solves
Legacy text-to-speech engines often sound mechanical, demand extensive speaker-specific fine-tuning datasets, or rely heavily on proprietary cloud voice APIs (such as ElevenLabs or OpenAI Audio APIs) that introduce privacy risks and recurring cost bottlenecks. BreezeTTS2 enables fully offline, real-time voice synthesis with context-aware prosody and dynamic voice cloning from a brief 3-second reference audio clip on consumer hardware.

## Where it fits in the stack
**Process & Understanding / Text-to-Speech (TTS).** BreezeTTS2 sits at the voice output generation layer of an agentic audio pipeline, turning text generated by local models (e.g., [Qwen](../ai_knowledge/qwen.md), [Llama 4](../ai_knowledge/local_llms.md)) or cloud models ([Claude 5.6](../ai_knowledge/claude-macos.md)) into expressive human-like speech before delivery to client applications.

## Typical use cases
- **Interactive Autonomous Assistants**: Generating real-time spoken responses in local home automation setups ([Home Assistant](../../services/home-assistant.md)).
- **Zero-Shot Voice Cloning**: Synthesizing customized voiceovers for documentation, podcasts, and automated news summaries using short reference clips.
- **Offline Accessibility Tools**: Providing high-speed, natural screen reading and auditory interface feedback on edge devices without cloud connectivity.
- **Multimodal Conversational Swarms**: Streaming low-latency voice feedback in multi-agent orchestration loops via [n8n](../../services/n8n.md) or custom Python services.

## Strengths
- **Frontier Audio Realism**: Produces high-sample-rate (44.1kHz), natural speech with proper emotional inflections and punctuation pauses.
- **Fast Zero-Shot Cloning**: Requires only 3 to 5 seconds of clean reference audio to replicate speaker timbre and cadence.
- **Low Latency & High Throughput**: Optimized ONNX and TensorRT export paths enable sub-100ms first-chunk audio streaming on NVIDIA GPUs and Apple Silicon.
- **Multilingual Support**: Supports native accent switching across English, Mandarin, Spanish, Japanese, and German.

## Limitations
- **VRAM Requirements**: Requires at least 6GB VRAM for real-time FP16 batch synthesis, though INT8 quantized checkpoints support 4GB configurations.
- **Sensitivity to Reference Noise**: Background noise or room echo in the reference audio clip can degrade cloned voice quality.
- **Pronunciation of Rare Technical Jargon**: May require phonetic spelling or custom dictionary hints for specialized domain terms.

## When to use it
- When you need high-fidelity, private text-to-speech synthesis running completely offline.
- When building low-latency conversational voice bots that demand instant response streaming.
- As a self-hosted alternative to proprietary commercial TTS API platforms.

## When not to use it
- When running on extremely constrained microcontrollers or embedded edge devices without hardware accelerators (use lightweight eSpeak-NG instead).
- For pure speech-to-text / transcription tasks (use [faster-whisper](faster-whisper.md) or [NeMo Speech](nemo-speech.md) instead).

## Getting started

### Installation
```bash
pip install breezetts2 torch torchaudio
```

### Basic Usage
```python
from breezetts2 import BreezeTTSModel
import torchaudio

# Initialize local BreezeTTS2 pipeline
model = BreezeTTSModel.from_pretrained("breezetts/breezetts2-base", torch_dtype="float16")

# Synthesize speech from text
audio_waveform, sample_rate = model.synthesize(
    text="Hello! BreezeTTS2 provides frontier quality speech synthesis running entirely on your local machine.",
    speaker_prompt="default"
)

# Save output audio to disk
torchaudio.save("output.wav", audio_waveform, sample_rate)
```

## CLI examples

### 1. Synthesize Audio to File
```bash
breezetts2 synthesize --text "BreezeTTS2 handles high-throughput voice generation offline." --output output.wav --voice default
```

### 2. Zero-Shot Voice Cloning via CLI
```bash
breezetts2 clone --ref-audio sample.wav --text "Cloning your voice in real-time with zero shot latency." --output cloned.wav
```

## API examples

### Programmatic Python Synthesis with Pydantic v2 Audio Metadata Validation
The following example demonstrates invoking BreezeTTS2 programmatically and using strict **Pydantic v2** validation to verify generated audio parameters (sample rate, channel count, and payload size) before streaming or saving.

```python
import io
import sys
from typing import Literal
from pydantic import BaseModel, Field, ValidationError, model_validator

# Define strict Pydantic v2 schemas for TTS payload metadata
class TTSRequestConfig(BaseModel):
    text: str = Field(..., min_length=1, max_length=2000, description="Input text to synthesize")
    language: str = Field(default="en", description="Target ISO language code")
    voice_speed: float = Field(default=1.0, ge=0.5, le=2.0, description="Speech rate multiplier")

class SynthesizedAudioMetadata(BaseModel):
    sample_rate: int = Field(..., ge=16000, le=48000, description="Audio sample rate in Hz")
    channels: int = Field(..., ge=1, le=2, description="Channel count (1=mono, 2=stereo)")
    duration_seconds: float = Field(..., gt=0.0, description="Audio duration in seconds")
    audio_format: Literal["wav", "flac", "mp3"] = Field(..., description="Container format")
    payload_size_bytes: int = Field(..., gt=0, description="Size of output raw audio payload")

    @model_validator(mode="after")
    def validate_audio_bounds(self) -> "SynthesizedAudioMetadata":
        if self.payload_size_bytes < 1000:
            raise ValueError("Audio payload size is suspiciously small; possible generation artifact.")
        return self

def generate_and_validate_speech(config: TTSRequestConfig) -> SynthesizedAudioMetadata:
    # Simulated BreezeTTS2 synthesis pipeline execution
    print(f"Synthesizing text: '{config.text[:30]}...' at speed {config.voice_speed}x")

    # Mock audio binary output generation (e.g. 44.1kHz mono WAV, 3.2 seconds duration)
    sample_rate = 44100
    channels = 1
    duration = 3.2
    mock_payload = b"\x00" * (sample_rate * 2 * int(duration))

    raw_metadata = {
        "sample_rate": sample_rate,
        "channels": channels,
        "duration_seconds": duration,
        "audio_format": "wav",
        "payload_size_bytes": len(mock_payload)
    }

    # Validate output with Pydantic v2
    validated_meta = SynthesizedAudioMetadata.model_validate(raw_metadata)
    return validated_meta

if __name__ == "__main__":
    try:
        req = TTSRequestConfig(text="Welcome to local intelligence orchestration with BreezeTTS2!")
        result = generate_and_validate_speech(req)
        print("BreezeTTS2 Synthesis Metadata validated successfully via Pydantic v2:")
        print(f"  Sample Rate: {result.sample_rate} Hz")
        print(f"  Duration: {result.duration_seconds}s")
        print(f"  Payload Size: {result.payload_size_bytes} bytes")
    except ValidationError as e:
        print(f"Metadata validation error: {e}", file=sys.stderr)
```
